# p0.1 — Crate scaffold + config + flight recorder

**Branch:** p0.1-scaffold  
**Phase:** 0 — Single-agent spike  
**Depends on:** nothing  
**Review status:** APPROVED (autoplan — CEO + Eng + DX + Outside Voice, 2026-06-07)

## Goal

A `cargo run` that loads a TOML config and writes a structured event to an
append-only flight log. The plumbing layer, nothing more.

## Scope

Create `agentd/` as a binary crate (Rust 2021):

- **`agentd/Cargo.toml`**: `tokio = { features = ["rt-multi-thread", "macros"] }`,
  `serde`, `serde_json`, `toml`, `chrono`, `anyhow`, `tracing`, `tracing-subscriber`.
  Dev-deps: `tempfile = "3"`. Size-optimized release profile
  (`opt-level = "z"`, `lto = true`, `strip = true`, `codegen-units = 1`,
  `panic = "abort"`).
- **`agentd/src/main.rs`**: `#[tokio::main]`, init `tracing` to stderr (`RUST_LOG`
  env filter, default `info`), load config from argv[1] (default `agent.toml`),
  init the flight recorder, log an `agent_spawned` event, exit 0.
- **`agentd/src/config.rs`**: `Config` / `AgentConfig` / `ModelConfig` / `ToolsConfig`
  with serde defaults; `#[serde(deny_unknown_fields)]` on `Config`. Secrets are
  never in config — env only. ModelConfig defaults: provider = `"anthropic"`,
  model = `"claude-sonnet-4-6"`, max_tokens = 4096.
- **`agentd/src/flight_recorder.rs`**: `FlightRecorder` wrapping a `Mutex<File>`.
  `new(path) -> anyhow::Result<Self>` — open failure is fatal, returns `Err`.
  `record(agent, turn, kind, data)` — write failure is best-effort: `tracing::warn!`,
  no panic. Append JSONL: `{ts, agent, turn, kind, data}`. `turn` is `Option<u32>`,
  `null` for `agent_spawned`. `kind` is `EventKind` enum. Uses `lock().ok()` —
  never `lock().unwrap()`.
- **`agentd/agent.toml`**: example with `[agent]`, `[model]`, `[tools]`, each field
  annotated with inline TOML comments.
- **`agentd/README.md`**: 3-step quickstart (export key, cargo run, tail the log).
- **`LICENSE`**: Apache-2.0.
- **`.github/workflows/ci.yml`**: cargo build + clippy (-D warnings) + test on push/PR.

## Acceptance Criteria

1. `cargo build` (debug + release) succeeds; `cargo clippy -- -D warnings` clean.
2. `cargo run -- agent.toml` appends one well-formed JSONL line to `flight.jsonl`
   and exits 0.
3. Loading a missing/invalid config gives a single-line error message (naming the
   path) and exits non-zero (no panic, no backtrace under normal `RUST_BACKTRACE`).

## Key design decisions (locked by review)

### EventKind as Rust enum

```rust
#[derive(Debug, serde::Serialize)]
#[serde(rename_all = "snake_case")]
pub enum EventKind {
    AgentSpawned,
    Perceive,
    InferenceRequest,
    InferenceResponse,
    ToolCall,
    ToolResult,
    Observe,
    AgentCompleted,
    BudgetExceeded,
    MaxTurnsReached,
    Error,
}
```

Serializes to `"agent_spawned"` etc. in JSONL. p0.1 only uses `AgentSpawned`;
remaining variants are placeholders that become active from p0.4 onward.
Compile-time exhaustiveness prevents typos when event kinds are emitted.

### FlightRecorder error contract

- `FlightRecorder::new(path: &Path) -> anyhow::Result<Self>` — open failure → `Err`,
  propagated to `main`, exits non-zero with context message. Configuration error.
- `FlightRecorder::record(...)` — write failure → `tracing::warn!("flight record
  failed: {e}")`, returns `()`. Best-effort. The agent run continues.
- `lock().ok()` throughout — Mutex poison gives `None`, caught and warned.

### tokio features

`["rt-multi-thread", "macros"]` not `["full"]`. p0.1 has no real async work; this
bounds binary size before p0.2 adds `reqwest` + `native-tls` toward the 2 MB target.

## Failure Modes

| Failure | Behavior |
|---|---|
| Config file missing | `fs::read_to_string` Err + `.context("loading config from {path:?}")` → single-line error, exit 1 |
| Config file invalid TOML | `toml::from_str` Err + context → single-line message with path, exit 1 |
| `flight.jsonl` unwritable on open | `FlightRecorder::new` returns `Err` → main prints error, exit 1 |
| Write fails mid-run (disk full) | `tracing::warn!`, write dropped, run continues |
| Mutex poisoned | `lock().ok()` returns `None`, `tracing::warn!`, write dropped, run continues |
