# p7.7 — Management HTTP API

**Version:** v0.53.0
**Depends on:** dx.1 (done)
**Branch:** `p7.7-management-http-api`

## Goal

Add an HTTP management API on `:7999` so `agentctl watch` works identically on Mac (outside Docker) and Linux (outside the QEMU VM) without FUSE filesystem access. This is the structural unlock for the deployment story: operators see the same dashboard whether they're running `agentctl watch` locally or over a Docker/QEMU port bind.

## Background

- `egress.rs` already uses hyper 1.x + hyper-util in `agentd` — the pattern and dependencies are proven.
- `SchedulerSnapshot` / `AgentSnapshot` live in `surfaces/` and drive the FUSE surface; they need `Serialize` added for JSON API responses.
- `FlightRecorder.record()` currently writes to disk only — needs a broadcast channel so SSE subscribers get live events.
- `agentctl watch` reads FUSE text files via `reader.rs`; needs an HTTP read path as a fallback.

## Scope

### 1. `agentd/src/management.rs` (new)

`ManagementServer` binds `127.0.0.1:7999` by default (loopback-only, same guard as `egress.rs`). Enabled only when `[management] enabled = true` in agent TOML (default: false). Port configurable via `[management] port`. Bind address configurable via `[management] bind_addr` (default `"127.0.0.1"`).

Hard-fail at startup if the bound address is not loopback (mirrors `egress.rs` line 543 guard). An operator who needs `0.0.0.0` for Docker host-to-container routing can set `bind_addr = "0.0.0.0"` explicitly.

Uses the same hyper 1.x + hyper-util pattern as `egress.rs`.

Routes:
- `GET /api/v1/agents` → JSON array of `AgentSnapshot`. Clone snapshot under read lock, serialize after releasing lock (prevents read-lock starvation of scheduler writes).
- `GET /api/v1/agents/:id` → single `AgentSnapshot` or `{"error":"not found"}` 404.
- `GET /api/v1/stream` → SSE stream. `ManagementServer` holds the `broadcast::Sender<String>`; each SSE connection calls `sender.subscribe()` to get its own `Receiver`. On `RecvError::Lagged(n)`, emit `data: {"lagged": N}\n\n` then continue (client knows it missed events). Client disconnect → task exits on next write error → receiver dropped.
- `GET /api/v1/approvals` → JSON of `pending_actions` from `SchedulerSnapshot`.
- `GET /api/v1/memory/:ns` → paginated entries for namespace; accepts `?limit=N&offset=M` (default limit 100). Returns `{"error":"memory unavailable"}` 503 when store absent. Namespace may be URL-encoded if it contains `/`.
- `GET /health` → `{"ok":true}` (used by agentctl auto-detect).

All 4xx/5xx responses return JSON body `{"error": "<message>"}` with `Content-Type: application/json`.

Flight events:
- `ManagementStarted { addr: String }` on successful bind.
- `ManagementRequest { method, path, status: u16 }` per request (best-effort, non-blocking — `let _ = tx.send(...)`).

### 2. `surfaces/Cargo.toml` + `surfaces/src/snapshot.rs`

Add `serde = { version = "1", features = ["derive"] }` to `surfaces/Cargo.toml`.

Add `#[derive(Serialize)]` to: `AgentSnapshot`, `SchedulerSnapshot`, `PendingActionView`, `SandboxSummary`, `ServerEnforcement`.

**Do NOT derive `Serialize` on `AgentStatus`** — it has tuple variants (`AwaitingChild(String)`, `AwaitingApproval(String)`) that derive would serialize as `{"AwaitingChild": "x"}`, inconsistent with the FUSE `as_str()` format. Instead:
- Annotate `AgentSnapshot.status` with `#[serde(serialize_with = "serialize_status_str")]` → serializes as the `as_str()` string.
- Add `#[serde(skip_serializing_if = "Option::is_none")] status_detail: Option<String>` field on the serialized shape (or computed inline) carrying the inner string for `AwaitingChild`/`AwaitingApproval`. This keeps wire format consistent with FUSE.

The FUSE text format in `agents_fs.rs` stays as-is; `Serialize` is additive.

### 3. `FlightRecorder` SSE fan-out

Add `broadcast_tx: Option<tokio::sync::broadcast::Sender<String>>` field to `FlightRecorder`.

Keep `new()` and `open()` constructors unchanged — they set `broadcast_tx = None`. Add:
```rust
pub fn with_broadcast(mut self, tx: broadcast::Sender<String>) -> Self {
    self.broadcast_tx = Some(tx);
    self
}
```

In `FlightRecorder::record()`, after `writeln!`:
```rust
if let Some(tx) = &self.broadcast_tx {
    let _ = tx.send(line); // non-blocking; Err means no live receivers
}
```

`ManagementServer` holds `Arc<broadcast::Sender<String>>`. Each SSE connection calls `sender.subscribe()` to get its own receiver cursor.

### 5. `agentd/src/main.rs`

Wire `ManagementServer` after FUSE mount:
```rust
if cfg.management.enabled {
    let (bcast_tx, _) = tokio::sync::broadcast::channel(1024);
    let recorder = recorder.with_broadcast(bcast_tx.clone());
    let snapshot = Arc::clone(&snapshot);
    let mem_store = memory_store.clone();
    tokio::spawn(management::serve(
        cfg.management.clone(), snapshot, mem_store, bcast_tx, recorder.clone()
    ));
}
```

When management is disabled (the common case), `FlightRecorder` is constructed without `with_broadcast()` — no change to existing tests or startup path.

### 6. `agentctl/src/watch/` — HTTP backend

Expand `DataSource` trait (new file `watch/source.rs` or inline in `reader.rs`):
```rust
pub trait DataSource: Send + Sync {
    fn load_agents(&self)        -> anyhow::Result<Snapshot>;
    fn load_approvals(&self)     -> anyhow::Result<Vec<PendingAction>>;
    fn load_memory_ns(&self, ns: &str) -> anyhow::Result<Vec<MemoryEntry>>;
    fn sse_url(&self)            -> Option<String>;  // None for FuseSource
    fn supports_write(&self)     -> bool;             // false for HttpSource
}
```

Two impls:
- `FuseSource { agents_dir: PathBuf }` — existing FUSE text-file logic refactored out of `load_snapshot()`.
- `HttpSource { base_url: String }` — calls `/api/v1/agents`, `/api/v1/approvals`, `/api/v1/memory/:ns`.

`HttpSource::load_agents()` deserializes the API JSON into `agentctl::watch::reader::Snapshot` via an explicit `From<AgentSnapshot> for AgentInfo` impl. Mapping decisions:
- `AgentSnapshot.token_budget: u64` → `BudgetKind::Tokens(n)`, or `BudgetKind::Unlimited` when value equals `u64::MAX` (the sentinel used by FUSE).
- `AgentSnapshot.tier: Option<String>` → `AgentInfo.tier` and `AgentInfo.isolation` (split on `":"` if present, e.g. `"universal:gvisor"`).
- `AgentSnapshot.short_term_previews` / `accessible_server_names` / `capabilities_unrestricted` — new optional fields on `AgentInfo` (all `#[serde(default)]`).

Inspector view uses `sse_url()` when present (connect to `/api/v1/stream`); falls back to local `flight.jsonl` read when `None` (FuseSource).

Auto-detect in `watch::run()`:
1. If `--url` flag or `AGENTCTL_URL` env var set → use `HttpSource` (skip FUSE startup validation).
2. Else if `<agents-dir>/system/budget` is readable → use `FuseSource`.
3. Else → try `{default_url}/health`; if 200 → use `HttpSource`.
4. Else → fail with: `"Start agentd with [management] enabled = true, or point --agents-dir at the FUSE mountpoint."`

On `HttpSource`, FUSE-only features (control file injection for `inject`/`spawn`) emit `[warn] control file unavailable in HTTP mode`.

`agentctl watch` args:
```
--url <URL>    Management API base URL (env: AGENTCTL_URL); overrides FUSE auto-detect
               Example: --url http://localhost:7999
```

## What's NOT in scope

- Authentication / authorization (loopback + Docker port-bind is sufficient for single-tenant; auth is dx.2).
- WebSocket transport (SSE sufficient for read-only streaming).
- `agentctl inject` / `agentctl spawn` via HTTP (FUSE control file is the write path; HTTP is read-only in p7.7).
- HTTP approval write endpoints (dx.2).
- `/api/v1/memory/:ns` write endpoint (read-only in p7.7).
- TLS (loopback / Docker bridge; not needed for single-tenant).

## Acceptance criteria

1. `agentctl watch --url http://localhost:7999` on the Mac host (outside Docker) shows the same Dashboard, AgentDetail, Topology, Memory, and Approvals views as `agentctl watch` inside the container using FUSE.
2. Inspector view streams live flight events over SSE with no polling lag when using HTTP mode.
3. Port unavailable → `agentctl watch` (without `--url`) falls back to FUSE with `[warn]`; or fails cleanly with actionable message if FUSE also absent.
4. `GET /api/v1/agents` returns valid JSON; `status` field is a string (`"running"`, `"awaiting_child"`, etc.), not a serde enum object.
5. `GET /api/v1/stream` delivers SSE; two concurrent connections both receive events; lagged receiver gets `{"lagged": N}` event.
6. Default bind is `127.0.0.1`; binding to a non-loopback address hard-fails at startup.
7. Binary stays ≤ 6 MB (check with `ls -la target/release/agentd` before tagging).
8. `cargo test` passes with ≥ 20 new tests.
