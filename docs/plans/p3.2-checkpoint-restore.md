### Performance

- `CheckpointStore::save()` must use `tokio::fs::write()` (not `std::fs`) — scheduler runs in async context; blocking I/O would block the tokio executor.
- Serialization cost: O(n) in message history. At 100 turns / ~1KB per pair = ~100KB JSON, <1ms on SSD. Negligible.

### Invariants preserved

- **Secrets**: `AgentConfig` has no `api_key` field. API key lives only in `AnthropicGateway` (read from env). Checkpoint is safe to write to disk.
- **No panic on bad input**: corrupt `checkpoint.json` → rename, log, start fresh. Never panic, never crash.
- **Metered cognition**: `tokens_spent` is checkpointed and restored. After a hard crash, in-flight API calls are lost and their tokens are not counted — this understatement is accepted and documented.
- **Record everything**: `AgentCheckpointed` and `AgentRestored` events emitted to `flight.jsonl`.

### Accepted behaviors (document in code)

1. **`deferred` queue**: agents sitting in `BinaryHeap<DeferredInfer>` remain in `state.agents` (they are not removed). On restore, `step_need_infer()` regenerates the `InferenceRequest` — equivalent to the deferred state being re-derived.
2. **`tokens_spent` after crash**: in-flight requests dropped at crash time. Restored `tokens_spent` reflects only checkpointed value, not the lost in-flight tokens. Margin of understatement: < `max_concurrent_inferences × max_tokens_per_call`.
3. **`checkpoint_dir` = CWD**: hardcoded for p3.2. Acceptable for dev and QEMU target. Flag in TODOS for `checkpoint_dir` config option before production.

## Failure modes

| Scenario | What happens |
|----------|-------------|
| Crash mid-write to `.tmp` | `checkpoint.json` untouched; next SIGTERM or turn writes a fresh `.tmp`; previous good checkpoint survives |
| Crash after rename | `checkpoint.json` is the new checkpoint; previous good checkpoint is gone; in-flight tokens understated |
| Corrupt `checkpoint.json` | Renamed to `checkpoint.json.corrupt`; agentd starts fresh from TOML |
| `checkpoint.json` from a newer format\_version | `load()` returns `Err`; treated as corrupt; renamed, start fresh |
| SIGTERM during checkpoint write | `checkpoint.json.tmp` left on disk (incomplete); next start ignores `.tmp` files, starts fresh from TOML |
| New TOML agent not in checkpoint | Starts fresh alongside restored agents; no conflict |
| Agent completed before checkpoint | `terminal=true` → excluded from `SchedulerCheckpoint::agents`; on restore it simply doesn't appear |

### Task 2 — New file: `agentd/src/checkpoint.rs`

```rust
use std::{
    collections::HashMap,
    path::{Path, PathBuf},
};

use anyhow::{Context, Result};
use serde::{Deserialize, Serialize};
use tokio::fs;

use crate::{
    bus::MailMessage,
    config::{AgentConfig, ModelConfig},
    inference::mod_::{InferenceResponse, Msg, ToolSpec},
};

pub const FORMAT_VERSION: u32 = 1;

#[derive(Debug, Serialize, Deserialize)]
pub struct AgentCheckpoint {
    pub agent_id:        String,
    pub cfg:             AgentConfig,
    pub model_cfg:       ModelConfig,
    pub messages:        Vec<Msg>,
    pub specs:           Vec<ToolSpec>,
    pub total_input:     u64,
    pub total_output:    u64,
    pub turn:            u32,
    pub stored_response: Option<InferenceResponse>,
    pub terminal:        bool,  // always false when saved; guards against race
}

#[derive(Debug, Serialize, Deserialize)]
pub struct AwaitingEntry {
    pub child_id:  String,
    pub parent_id: String,
    pub call_id:   String,
}

#[derive(Debug, Serialize, Deserialize)]
pub struct SchedulerCheckpoint {
    pub format_version: u32,
    pub agents:         Vec<AgentCheckpoint>,
    pub awaiting:       Vec<AwaitingEntry>,
    pub mailboxes:      HashMap<String, Vec<MailMessage>>,
    pub tokens_spent:   u64,
    pub child_seq:      u64,
    pub spawn_depths:   HashMap<String, u32>,
}

pub struct CheckpointStore {
    path:     PathBuf,
    tmp_path: PathBuf,
}

impl CheckpointStore {
    pub fn new(dir: &Path) -> Self {
        let path = dir.join("checkpoint.json");
        let tmp_path = dir.join("checkpoint.json.tmp");
        Self { path, tmp_path }
    }

    pub async fn save(&self, cp: &SchedulerCheckpoint) -> Result<()> {
        let json = serde_json::to_string(cp).context("serialize checkpoint")?;
        fs::write(&self.tmp_path, &json)
            .await
            .context("write checkpoint.json.tmp")?;
        fs::rename(&self.tmp_path, &self.path)
            .await
            .context("rename checkpoint.json.tmp -> checkpoint.json")?;
        Ok(())
    }

    pub fn load(&self) -> Result<Option<SchedulerCheckpoint>> {
        if !self.path.exists() {
            return Ok(None);
        }
        let bytes = std::fs::read(&self.path).context("read checkpoint.json")?;
        let cp: SchedulerCheckpoint =
            serde_json::from_slice(&bytes).context("parse checkpoint.json")?;
        if cp.format_version > FORMAT_VERSION {
            anyhow::bail!(
                "checkpoint format_version {} > supported {}",
                cp.format_version,
                FORMAT_VERSION
            );
        }
        Ok(Some(cp))
    }
}
```

### Task 5 — `scheduler.rs` — periodic checkpoint + SIGTERM checkpoint

1. Add `CheckpointStore` field to `SchedulerState` (or thread it via `Scheduler::new()`).
2. At the `provide_tool_results` boundary: after `turn` increments, if `turn % checkpoint_interval_turns == 0` (and `interval > 0`), call `store.save(snapshot).await` with a `FlightRecorder::record(AgentCheckpointed)` call. Log failures as warnings (best-effort; never propagate to kill the agent).
3. At the SIGTERM exit path (after `shutdown_requested` drains the loop): build `SchedulerCheckpoint` from current state (filter `terminal=true` agents), call `store.save(snapshot).await`, emit `AgentCheckpointed` per agent.

Note: `deferred` queue (`BinaryHeap<DeferredInfer>`) is NOT checkpointed — on restore, agents in `state.agents` are in `NeedInfer` state and `step_need_infer()` regenerates the `InferenceRequest` equivalently. Document this with a comment at the save site.

### Task 6 — `main.rs` — restore path

Insert before `Scheduler::new()` in `run_agent()`:

```rust
let store = CheckpointStore::new(Path::new("."));
let agent_overrides: HashMap<String, AgentCheckpoint> = match store.load() {
    Ok(Some(cp)) => {
        // emit AgentRestored for each agent
        for agent_cp in &cp.agents {
            recorder.record(&agent_cp.agent_id, None, EventKind::AgentRestored, json!({}));
        }
        cp.agents.into_iter().map(|a| (a.agent_id.clone(), a)).collect()
    }
    Ok(None) => HashMap::new(),
    Err(e) => {
        tracing::error!("corrupt checkpoint, starting fresh: {e:#}");
        // rename corrupt file for forensics
        let _ = std::fs::rename("checkpoint.json", format!(
            "checkpoint.json.corrupt.{}", SystemTime::now()...
        ));
        HashMap::new()
    }
};
// delete checkpoint after successful restore
if !agent_overrides.is_empty() {
    let _ = std::fs::remove_file("checkpoint.json");
}
// agents in checkpoint override TOML for their IDs; new TOML agents start fresh
```
