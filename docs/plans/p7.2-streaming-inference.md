# p7.2 — Streaming Inference

**Branch:** `p7.2-streaming-inference`
**Target version:** v0.36.0
**Depends on:** p7.1 (reqwest `stream` feature already enabled)

## Goal

Add opt-in SSE streaming from the Anthropic Messages API so text chunks are
written to stdout progressively as the model generates them, rather than only
after the full response arrives. The existing run-to-completion path is
**unchanged**; streaming is opt-in via `streaming = true` in the global `[model]`
config (applies to all agents in the config file).

Note: streaming applies to **all inference turns**, not just the final answer.
Intermediate tool-result commentary and reasoning text also appear on stdout.

## Architecture

### Flag propagation

`streaming: bool` is added to **both** `ModelConfig` (TOML config) and
`InferenceRequest` (wire type). The critical propagation point is
`agent/mod.rs:522` — **this site must use `self.model_cfg.streaming`**, not
`false`. Getting it wrong silently breaks the feature (all tests pass but
no chunks appear at runtime):

```rust
// agent/mod.rs:522 — THE load-bearing propagation point
AgentEffect::Infer(InferenceRequest {
    system:     None,
    messages:   self.messages.clone(),
    tools:      self.specs.clone(),
    max_tokens: self.model_cfg.max_tokens,
    streaming:  self.model_cfg.streaming,   // ← must NOT be false
})
```

`DeferredInfer` already stores `InferenceRequest`, so the flag naturally
propagates through both `enqueue_or_defer()` and `drain_deferred()`.

```rust
// inference/mod.rs — new field on InferenceRequest
pub struct InferenceRequest {
    pub system:     Option<String>,
    pub messages:   Vec<Msg>,
    pub tools:      Vec<ToolSpec>,
    pub max_tokens: u32,
    pub streaming:  bool,   // set from ModelConfig.streaming via agent/mod.rs:522
}
```

### Trait extension

`InferenceGateway` gets a second async method with a **default fallback** so
all existing impls (including mock gateways in tests) compile unchanged:

```rust
// inference/mod.rs
async fn infer_with_stream(
    &self,
    req: InferenceRequest,
    chunk_tx: tokio::sync::mpsc::UnboundedSender<String>,
) -> Result<InferenceResponse> {
    drop(chunk_tx);          // no chunks — caller sees text_chunks_emitted: 0
    self.infer(req).await
}
```

`AnthropicGateway` overrides this method with real SSE logic. Its SSE loop
must check `chunk_tx.send(delta.text)` — if it returns `Err` (receiver
dropped due to BrokenPipe), break the SSE loop and return early.

### Anthropic SSE streaming

POST `/v1/messages` with `"stream": true`. Parse the `text/event-stream`
response line-by-line from `response.bytes_stream()`, with a private
`parse_sse_event()` helper to manage cyclomatic complexity.

SSE invariants:
- Lines are stripped of trailing `\r` before JSON parsing (CRLF safety)
- `line_buf` is capped at 1 MB — returns `Err` if exceeded
- Blocks assembled in strict SSE **index order** (preserves model's ordering)
- Empty text deltas (`delta.text == ""`) are filtered and not sent to `chunk_tx`
- Anthropic `error`-type events → return `Err` with the API error message
- `InferenceStreamCompleted` emitted **only on `Ok(resp)`**, not on `Err`
- `chunk_tx.send()` returns `Err` when receiver is dropped → break SSE loop

Relevant SSE events:

| Event type | Action |
|------------|--------|
| `message_start` | Extract `usage.input_tokens` |
| `content_block_start` | Register block by index: `text` or `tool_use` |
| `content_block_delta / text_delta` | Skip if empty; else `chunk_tx.send(delta.text)` (check Err) + append to text accumulator |
| `content_block_delta / input_json_delta` | Append to tool-use input accumulator (not sent to chunk_tx) |
| `content_block_stop` | Finalise block |
| `message_delta` | Extract `stop_reason` and `usage.output_tokens` |
| `message_stop` | End of stream — assemble `InferenceResponse` and return |
| `error` | Return `Err` with the API error message |

Block accumulators (keyed by SSE `index`):

```rust
enum BlockAcc {
    Text { buf: String },
    ToolUse { id: String, name: String, input_json: String },
}
```

Final `InferenceResponse.blocks` assembled by sorting accumulator by SSE `index`
ascending. Identical ordering contract to the non-streaming path.

### Scheduler integration

Extract a private `dispatch_infer_request()` helper to avoid duplicating the
~30-line streaming dispatch block in both `enqueue_or_defer` and `drain_deferred`.
Both call sites call this helper.

The helper signature:
```rust
fn dispatch_infer_request(
    req: InferenceRequest,
    id: String,
    turn: u32,
    is_multi: bool,
    gw: Arc<dyn InferenceGateway + Send + Sync>,
    recorder: Arc<FlightRecorder>,
    streamed_agents: Arc<Mutex<HashSet<String>>>,
) -> PendingFut
```

Inside `dispatch_infer_request`:

```rust
Box::pin(async move {
    let result = if req.streaming {
        recorder.record(EventKind::InferenceStreamStarted, json!({
            "agent_id": &id, "model": gw.model_id(),
        }));
        let (tx, mut rx) = tokio::sync::mpsc::unbounded_channel::<String>();
        let agent_id_label = id.clone();
        let infer_fut = gw.infer_with_stream(req, tx);
        // print_fut returns chunks_emitted — async stdout avoids blocking worker
        let print_fut = async move {
            use tokio::io::AsyncWriteExt;
            let mut stdout = tokio::io::stdout();
            let mut chunks_emitted: u64 = 0;
            while let Some(chunk) = rx.recv().await {
                let line = if is_multi {
                    format!("[{agent_id_label}] {chunk}")
                } else {
                    chunk
                };
                match stdout.write_all(line.as_bytes()).await {
                    Err(e) if e.kind() == std::io::ErrorKind::BrokenPipe => {
                        return chunks_emitted;
                    }
                    _ => {}
                }
                let _ = stdout.flush().await;
                chunks_emitted += 1;
            }
            // Ensure final newline so shell prompt starts on a fresh line
            let _ = stdout.write_all(b"\n").await;
            chunks_emitted
        };
        let (infer_result, chunks_emitted) = tokio::join!(infer_fut, print_fut);
        if let Ok(ref resp) = infer_result {
            if chunks_emitted > 0 {
                streamed_agents.lock().unwrap().insert(id.clone());
            }
            recorder.record(EventKind::InferenceStreamCompleted, json!({
                "agent_id": &id,
                "text_chunks_emitted": chunks_emitted,
                "input_tokens": resp.input_tokens,
                "output_tokens": resp.output_tokens,
            }));
        }
        infer_result
    } else {
        gw.infer(req).await
    };
    EffectResult::Inference { agent_id: id, result }
})
```

Note: `text_chunks_emitted` in the flight payload reflects text chunks only.
Tool-only streaming turns legitimately produce 0 text chunks — this does NOT
indicate fallback. The presence of `InferenceStreamStarted` without
`InferenceStreamCompleted` signals an interrupted stream.

### `streamed_agents` side-channel

`Arc<Mutex<HashSet<String>>>` is added to `Scheduler` struct following the
same pattern as `Arc<RwLock<SchedulerSnapshot>>` for the FUSE surface:

```rust
// scheduler.rs
pub struct Scheduler {
    // ... existing fields ...
    streamed_agents: Arc<Mutex<HashSet<String>>>,
}

impl Scheduler {
    pub fn streamed_agents(&self) -> Arc<Mutex<HashSet<String>>> {
        Arc::clone(&self.streamed_agents)
    }
}
```

`main.rs` reads it after `scheduler.run()`:

```rust
let streamed = scheduler.streamed_agents();
let outcomes = scheduler.run().await;
for (id, result) in &outcomes {
    match result {
        Ok(answer) => {
            let was_streamed = streamed.lock().unwrap().contains(id.as_str());
            if !was_streamed {
                println!("{answer}");
            }
        }
        Err(e) => {
            tracing::error!(agent = %id, error = %e, "agent failed");
            any_failed = true;
        }
    }
}
```

### Config

```toml
[model]
provider   = "anthropic"
model      = "claude-sonnet-4-6"
max_tokens = 4096
streaming  = true      # opt-in; default false; applies to all agents in this config
```

Note: `ModelConfig` has `#[serde(deny_unknown_fields)]` (config.rs:258). Adding
`streaming` with `#[serde(default)]` is safe — existing configs without `streaming`
deserialize to `false`. All `ModelConfig { .. }` and `InferenceRequest { .. }`
struct literals in tests must add `streaming: false` (caught by `cargo test`).

### Flight events

Defined in `agentd/src/events.rs` (re-exported by `flight_recorder.rs`):

| kind | tier | payload |
|------|------|---------|
| `inference_stream_started` | 2 | `{ agent_id, model }` |
| `inference_stream_completed` | 2 | `{ agent_id, text_chunks_emitted, input_tokens, output_tokens }` |

`inference_stream_completed` is only emitted on `Ok(resp)`. On error, the existing
`Error` + `AgentFailed` events fire. `InferenceStreamStarted` without a corresponding
`InferenceStreamCompleted` in flight.jsonl signals an interrupted stream.

Note: `text_chunks_emitted == 0` on a successful stream means the model produced
tool-calls only (no text output) — it does NOT indicate a fallback. The default
`infer_with_stream` impl (non-Anthropic gateways) drops the channel and calls
`self.infer()` — it also produces 0 text chunks.
