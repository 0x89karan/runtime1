QA Report — ux.2a Attention

SHIP-READY Date: 2026-07-13 · Branch: ux.2a-attention · Commit: 3233ef83
Stack: Rust — agentd (headless agent runtime) + agentctl (terminal UI / CLI). No web app, no URL, no browser — standard browser-based /qa doesn't apply here. Testing was adapted to this stack: the full test suite as a regression baseline, plus a real live agentd process and the real compiled agentctl binary exercised end-to-end.

Approach

  1. cargo test --workspace as the regression baseline.
  2. A real, live agentd process (zero-agent docker/cockpit.toml config) serving the real management HTTP API on 127.0.0.1:7999.
  3. The real, compiled agentctl binary — both --plain mode and the interactive ratatui TUI — run against that live server, capturing actual output and checking for panics or crashes.

This exercises the full pipeline (agentd computes attention → serializes → real HTTP → real agentctl binary via reqwest → parses → renders) end-to-end — the seams between layers that unit tests, which test each layer in isolation, don't cover.

This is a real, honest gap, not a claim of full coverage.

Findings

Zero new bugs found. The two critical bugs in this feature — the since/"ago" epoch-vs-duration rendering bug, and EvaluationUnavailable never actually firing — were already found and fixed during the /review pass, before this QA pass started, both by dual-voice adversarial review (Claude subagent + Codex, independently converging on the same finding). This QA pass's live smoke test found nothing additional: no crashes, no panics, no malformed output, no regressions against the pre-existing 1338-test baseline.
